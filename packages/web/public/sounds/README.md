# Sound recordings

Almost every sound in Yahtzee Party is made in code (Web Audio). Two soccer sounds sound much
better as real recordings, so you can put them here:

| File                                 | Used for                                            |
| ------------------------------------ | --------------------------------------------------- |
| `crowd-roar.mp3` (or `.ogg`, `.wav`) | Crowd cheering at a Yahtzee and at the winner party |
| `goal.mp3` (or `.ogg`, `.wav`)       | "GOOOAL!" at a Yahtzee                              |

- Only use sounds you may use freely, such as **CC0** (public domain) sounds.
- Keep them short (2 to 4 seconds) and small (under 300 KB).
- If a file is missing, the game plays a made-up crowd or a stadium horn instead.

The files are copied into the build as they are, so nothing is downloaded while playing.
